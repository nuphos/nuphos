# 設計畫布（Design Canvas）— BDD 規格

## 概述

讓團隊和 AI 在 Nuphos 裡，把一個產品的所有畫面攤在同一張畫布上，一起看、一起改、一路點完流程，不用再離開 Nuphos。
行為以 Claude Design 為參考（只參考互動方式，不照搬程式碼、圖示、文案與樣式）。對應 issue：nuphos/nuphos#954。

名詞：

- **設計（Design）**：團隊層級的文件，內含多個頁面。
- **頁面（Page）**：一張無限畫布。
- **畫面框（Frame）**：畫布上的一個方框，裡面即時執行一段 HTML，代表產品的一個畫面。
- **分區（Section）**：有標題的區塊，用來把相關畫面框分組。
- **註記物件**：文字、便利貼、筆畫、形狀。

## 行為規格

### 場景 1：從團隊頁面進入設計

**Given** 使用者在某個團隊裡
**When** 使用者從側欄或 ⌘K 打開「Designs」
**Then** 看到這個團隊所有設計的列表（名稱、最後更新時間、建立者），可以搜尋，並有「New design」按鈕

### 場景 2：建立、重新命名、刪除設計

**Given** 使用者在 Designs 列表
**When** 按「New design」
**Then** 建立名為「Untitled design」的設計，內含一個「Page 1」，並直接打開它
**When** 使用者在列表右鍵選「Rename」或「Delete」
**Then** 名稱更新；刪除前會先跳確認，確認後設計從列表消失

### 場景 3：多頁面

**Given** 使用者打開一個設計
**When** 點左上角的頁面選單
**Then** 看到所有頁面，可以切換、新增、重新命名、複製、刪除頁面（最後一頁不能刪），切換頁面時畫布內容跟著換

### 場景 4：放置畫面框

**Given** 使用者在畫布上
**When** 選工具列的「Frame」工具並在畫布上點一下或拖出一個範圍
**Then** 出現一個畫面框，預設大小可在 Desktop（1440×900）、Tablet（834×1194）、Phone（390×844）間切換，框上方顯示可編輯的標題

### 場景 5：畫面框即時顯示 HTML

**Given** 畫面框有 HTML 內容
**When** 畫面框出現在畫面上
**Then** 它在沙盒中執行並顯示該 HTML（跟聊天裡的 HTML Artifact 一樣的隔離規則）；縮小檢視時仍看得到畫面，不會變成空白
**And** HTML 有錯誤時，框上出現錯誤提示，而不是整個畫布壞掉

### 場景 6：從聊天的 Artifact 加入畫布

**Given** 聊天中有一個 HTML Artifact
**When** 使用者在 Artifact 工具列選「Add to design」並選擇設計與頁面
**Then** 該頁面多出一個畫面框，內容是那個 Artifact 當下版本的 HTML，標題是 Artifact 標題

### 場景 7：畫面框的動作

**Given** 畫布上有畫面框
**When** 使用者點框標題旁的「下載」
**Then** 下載該畫面的 .html 檔
**When** 使用者點「Play」
**Then** 進入播放模式，從這個畫面開始
**When** 使用者雙擊畫面框
**Then** 進入框內互動：可以直接點、捲動框內的頁面；按 Esc 或點框外離開

### 場景 8：分區

**Given** 使用者在畫布上
**When** 用「Section」工具拖出一個範圍
**Then** 出現有標題的分區；移動分區時，完全在它裡面的畫面框與註記物件一起移動

### 場景 9：註記工具

**Given** 使用者在畫布上
**When** 使用工具列的 Text、Sticky note、Pen、Shape（矩形、橢圓、箭頭、直線）
**Then** 分別產生可編輯的文字、黃色便利貼、手繪筆畫、形狀；筆和形狀可以選顏色，形狀可以選種類

### 場景 10：選取與編輯物件

**Given** 畫布上有物件
**When** 使用 Select 工具點選、Shift 多選或框選
**Then** 物件被選取，可拖動、縮放（畫面框與形狀）、Delete 刪除、⌘C/⌘V 複製貼上、⌘⇧V 複製一份（⌘D 在 Nuphos 是分割視窗）
**And** ⌘Z / ⌘⇧Z 可以復原與重做

### 場景 11：流程連線

**Given** 畫布上有兩個以上畫面框
**When** 使用者從一個框的連接點拖到另一個框
**Then** 兩框間出現箭頭，代表「從 A 到 B」；箭頭可以加標籤（例如「按下送出」），可以刪除

### 場景 12：平移與縮放

**Given** 使用者在畫布上
**When** 用 Hand 工具或按住空白鍵拖曳、觸控板雙指滑動
**Then** 畫布平移
**When** ⌘ + 滾輪、觸控板捏合、或右上角縮放選單
**Then** 縮放（10%–400%），選單有「縮放至適合」「縮放至 100%」「縮放至選取」，並顯示目前百分比

### 場景 13：播放模式

**Given** 頁面上有畫面框
**When** 使用者按右上角的 Play，或某框的 Play
**Then** 全螢幕以原始大小顯示畫面，可以直接操作；有箭頭連出去時，下方出現前往下一個畫面的按鈕；左右方向鍵在連線順序中前後切換；Esc 回到畫布

### 場景 14：自動儲存與版本安全

**Given** 使用者在編輯設計
**When** 做任何修改
**Then** 變更自動儲存，不需要按儲存；重新整理或重開 App 後內容還在
**And** 同一個設計被 AI 或隊友同時修改時，畫布會更新成最新內容，不會用舊內容蓋掉別人的修改

### 場景 15：AI 建立與編輯設計

**Given** 使用者在聊天中請 AI「把登入流程的畫面做在設計畫布上」
**When** AI 執行
**Then** AI 可以建立設計、新增頁面、分區、畫面框（含 HTML）、便利貼與流程連線，也能修改既有畫面框的 HTML
**And** 使用者開著那個設計時，畫布即時出現 AI 的修改
**And** AI 回覆裡有連結，點了會打開那個設計

### 場景 16：從畫布叫 AI 修改畫面

**Given** 使用者選取了一個或多個畫面框
**When** 使用者按右鍵選「Ask agent to edit」並輸入要求
**Then** 開啟一個聊天，帶著這個設計與選取的畫面框資訊送出要求，AI 修改後畫布更新

### 場景 17：團隊權限

**Given** 使用者是團隊成員
**Then** 可以看與編輯該團隊所有設計
**Given** 使用者不是該團隊成員
**Then** API 拒絕讀取與修改那個團隊的設計

## Acceptance Criteria

- [ ] AC-01：團隊頁面有「Designs」入口（側欄與 ⌘K 都找得到），列表顯示名稱、更新時間、建立者，並支援搜尋
- [ ] AC-02：「New design」建立含「Page 1」的設計並立即打開；可重新命名；刪除前有確認
- [ ] AC-03：頁面選單可切換、新增、重新命名、複製、刪除頁面；不能刪除最後一頁
- [ ] AC-04：Frame 工具可放置畫面框，有 Desktop / Tablet / Phone 三種預設尺寸，標題可編輯
- [ ] AC-05：畫面框在沙盒中即時執行 HTML，沙盒規則與聊天 HTML Artifact 相同（無 same-origin、連結開在外部瀏覽器）
- [ ] AC-06：畫面框的 HTML 出錯時，框上顯示錯誤，畫布其他部分正常
- [ ] AC-07：HTML Artifact 工具列有「Add to design」，可選設計與頁面，加入後的畫面框內容與標題來自該 Artifact 版本
- [ ] AC-08：每個畫面框有下載（.html）與 Play 動作
- [ ] AC-09：雙擊畫面框進入框內互動，Esc 或點框外離開
- [ ] AC-10：Section 工具可建立有標題的分區；移動分區時，完全在其範圍內的物件一起移動
- [ ] AC-11：Text、Sticky note、Pen、Shape（矩形、橢圓、箭頭、直線）都能建立與編輯；筆和形狀可選顏色
- [ ] AC-12：Select 工具支援點選、Shift 多選、框選、拖動、縮放、Delete、⌘C/⌘V、⌘⇧V
- [ ] AC-13：⌘Z / ⌘⇧Z 可復原與重做畫布上的修改
- [ ] AC-14：可以在畫面框之間拉箭頭、加標籤、刪除
- [ ] AC-15：Hand 工具、空白鍵拖曳、觸控板可平移；⌘ + 滾輪、捏合、縮放選單可縮放，範圍 10%–400%，選單有適合、100%、縮放至選取，並顯示百分比
- [ ] AC-16：播放模式以原始大小顯示畫面且可操作；依連線顯示下一步按鈕；方向鍵前後切換；Esc 離開
- [ ] AC-17：修改自動儲存，重開後內容還在
- [ ] AC-18：同一設計有別人（AI 或隊友）修改時，開著的畫布會更新，且不會用舊資料覆蓋別人的修改
- [ ] AC-19：後端有團隊層級的設計 API（列表、建立、讀取、更新、刪除），非團隊成員被拒絕
- [ ] AC-20：AI 有內建 skill 說明如何透過 API 建立與修改設計（頁面、分區、畫面框 HTML、便利貼、連線），使用者開著設計時能即時看到變化
- [ ] AC-21：AI 回覆中的設計連結點了會在 App 內打開該設計
- [ ] AC-22：選取畫面框後右鍵「Ask agent to edit」會開啟帶有設計與畫面框資訊的聊天
- [ ] AC-23：既有功能不受影響：Desktop 與 Backend 的 typecheck、test、lint 全部通過

## 排除範圍（Out of Scope）

- 多人即時游標、在畫布上留言串
- 手動編輯畫面框內的 HTML 原始碼以外的視覺編輯（例如直接拖動框內按鈕）
- 上傳與擺放圖片
- iOS 與 Android 版本的設計畫布
- 匯出整頁為 PDF 或 PNG
- 從 Figma 或其他工具匯入
